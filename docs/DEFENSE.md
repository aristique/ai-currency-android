# Подготовка к защите

1. Установить artifacts/lab4-currency-debug.apk на Android 8.0+ или эмулятор.
2. При наличии сети открыть конвертер. Показать сумму, валюты, результат, дату и BNM.
3. Открыть «7 дней» и «30 дней», дождаться истории. Проверить число доступных дней и все статистики.
4. Включить режим полёта. Обновить курс: приложение должно показать сохранённый курс и его дату.
5. Закрыть приложение полностью, открыть без сети: файлы кэша должны сохраниться. Проверить оба исторических экрана.
6. Ввести пустую, отрицательную и нулевую сумму. Показать неактивную кнопку или сообщение.
7. Выбрать одинаковые валюты: сумма сохраняется, аналитика пары равна 1 и изменения равны нулю.
8. Показать историю Git и Pull Request.

Для объяснения кода: Domain — точные расчёты BigDecimal, деление Value/Nominal и статистика; Repository — сеть, ограничение ответа и постоянные XML-файлы; MainActivity — интерфейс и фоновый исполнитель; ChartView — визуализация реальных точек. Величины на графике можно рисовать через Double, но финансовые расчёты остаются в BigDecimal.

Формулы: результат = сумма × MDL за единицу исходной валюты / MDL за единицу целевой. Процент = (последний курс − первый) / первый × 100. Среднее вычисляется по доступным наблюдениям; число наблюдений показано явно.

Первый запуск без сети и без кэша не может дать настоящий курс. В таком случае требуется понятное сообщение, а не демонстрационные значения.
